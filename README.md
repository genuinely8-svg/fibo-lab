# 피보 -1 연구소

업비트 캔들로 하락 스윙의 피보나치 -1 레벨을 찾고, 과거에 -1을 찍은 뒤 얼마나 반등했는지 통계를 내는 페이지입니다.
## 실행 방법
```powershell
cd $HOME\Documents\fibo-lab
node server.js
```
그다음 브라우저에서 http://localhost:3000 을 열고 **분석하기**를 누르세요. 끌 때는 PowerShell 창에서 `Ctrl + C`.

`index.html`을 더블클릭해서 열거나 GitHub Pages에 올려도 동작하지만, 업비트가 브라우저 직접 요청을
10초에 1번만 허용해서 **느린 모드**(코인당 약 10초, 캔들 200개)로 돌아갑니다.

## 파일
- `server.js` — 업비트 요청을 대신 해주는 작은 서버 (설치할 것 없음)
- `index.html` — 화면 (표, 차트)
- `fib-core.js` — 계산 엔진 (스윙 찾기, -1 레벨, 반등/하락 통계)
- `test.js` — 계산 엔진 테스트 (`node test.js`)

## 계산 방법
1. 스윙 고점: 좌우 N개 봉보다 고가가 높은 봉. 스윙 저점도 같은 방식.
2. -1 레벨 = 저점 − (고점 − 저점)
3. 과거 하락 스윙 중 고점을 다시 넘기 전에 -1까지 내려간 경우를 "터치"로 기록
4. 터치 후 K개 봉 동안 최대 반등률과 최대 추가하락률을 평균 내서 표시

공부용 도구이며 투자 조언이 아닙니다.
